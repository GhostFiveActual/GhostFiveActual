## Projects

### [VECTIS](https://github.com/GhostFiveActual/vectis)

VECTIS is a programming language and toolchain I've been building for automation that needs to be understandable and verifiable. When software starts making decisions or carrying out increasingly complicated workflows, I want to know what it interpreted, what it was allowed to do, how it executed, and what actually happened. So I started working on a language with an inspectable compiler pipeline, execution graphs, explicit capability boundaries, and traceable results. It's one of those projects where solving one problem inevitably gives me three new things to learn.

### [OwnLedger](https://github.com/GhostFiveActual/OwnLedger)

OwnLedger is a free, offline-first personal finance desktop application. I wanted a way to manage budgets, bills, debt, savings, and financial decisions without needing another subscription or handing personal financial information to a cloud service. It includes local storage, financial planning tools, backups, and desktop packaging. I don't think useful software should need access to someone's private information when it can do its job perfectly well without it.

### [GitLedger](https://github.com/GhostFiveActual/GitLedger)

GitLedger came out of a problem I created for myself: too many repositories, half-finished experiments, old coursework, projects I hadn't touched in ages, and no sensible way to figure out what was worth keeping. It's a repository auditing and lifecycle management tool for reviewing, organizing, archiving, exporting, and cleaning up GitHub projects without blindly deleting things. Basically, it helps deal with the mess before making a bigger mess.
